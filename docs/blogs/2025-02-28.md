# motion 动画库的使用

最近 React 很火的动画库 [motion](https://motion.dev/)（原 framer-motion）在社区的支持下有了 Vue 的版本：[motion-vue](https://motion.unovue.com)。motion 的优势在于极小的包体积，结合 JavaScript 动画的灵活性与浏览器硬件加速（如 WebGL、CSS Transform），实现高性能动画效果。恰好最近的一个项目也用到了 motion 优化了搜索器的动画，故在此记录一下。

## 安装

```bash
# Vue
pnpm add motion-v
# React
pnpm add motion
```

以下均为 Vue 的使用方式，React 的使用方式基本类似。

## 使用

### 基础使用

<script setup>
import MotionBase from '../components/demo/MotionBase.vue'
import MotionVariants from '../components/demo/MotionVariants.vue'
import MotionPresence from '../components/demo/MotionPresence.vue'
import MotionReorder from '../components/demo/MotionReorder.vue'
</script>

```vue
<script setup lang="ts">
import { Motion } from 'motion-v'
</script>

<template>
  <Motion
    as="div"
    class="bg-[#00cf56] size-20 aspect-square rounded-2xl text-center leading-20"
    :animate="{
      scale: [1, 2, 2, 1, 1],
      rotate: [0, 0, 180, 180, 0],
      borderRadius: ['0%', '0%', '50%', '50%', '0%']
    }"
    :transition="{
      duration: 2,
      ease: 'easeInOut',
      times: [0, 0.2, 0.5, 0.8, 1],
      repeat: Infinity,
      repeatDelay: 1
    }">
    Hello
  </Motion>
</template>
```

通过 variants 属性，可以定义动画的各个阶段，通过 animate 属性指定当前动画的阶段。

```vue
<script lang="ts" setup>
import { Motion } from 'motion-v'
import { ref } from 'vue'

const animate = ref('show')

const variants = {
  show: {
    x: 0,
    y: 0,
    opacity: 1,
    scale: 1,
    transition: {
      duration: 0.5,
      ease: 'easeInOut'
    }
  },
  hide: {
    x: 100,
    y: 0,
    opacity: 0,
    scale: 0.5,
    transition: {
      duration: 0.5,
      ease: 'easeInOut'
    }
  }
}

function handleClick() {
  animate.value = animate.value === 'hide' ? 'show' : 'hide'
}
</script>

<template>
  <div>
    <button class="mb-[15px]" @click="handleClick">切换</button>
    <Motion class="size-20 bg-[#00cf56]" :animate="animate" :variants="variants"></Motion>
  </div>
</template>
```

### 结合 display: none 和组件销毁的使用

在使用纯 CSS 动画时，如果动画的元素在动画过程中被隐藏或销毁，动画会中断。motion 提供了 AnimatePresence 组件，用它将需要隐藏或者销毁的元素包裹住，以解决动画中断的问题。

```vue
<script setup lang="ts">
import { AnimatePresence, Motion } from 'motion-v'
import { ref } from 'vue'

const show = ref(true)
</script>

<template>
  <div class="flex flex-col items-center w-full">
    <button @click="show = !show">切换</button>
    <div class="size-40">
      <AnimatePresence>
        <Motion
          v-show="show"
          class="bg-[#00cf56] aspect-square rounded-2xl leading-40 text-center"
          :initial="{ scale: 0 }"
          :animate="{ rotate: 180, scale: 1 }"
          :exit="{ rotate: 0, scale: 0 }">
          Hello
        </Motion>
      </AnimatePresence>
    </div>
  </div>
</template>
```

## 与其他库对比

| 特性         | ​ ​Motion​         | ​GSAP​     | ​Anime.js​         |
| ------------ | ------------------ | ---------- | ------------------ |
| ​ 体积 ​     | 2.5kb（核心）      | 较大       | 轻量（比 GSAP 小） |
| ​ 性能 ​     | 混合引擎优化       | 高         | 中等               |
| ​ 框架集成 ​ | React/Vue 原生支持 | 需插件扩展 | 无框架绑定         |
| ​ 学习曲线 ​ | 低（声明式 API）   | 中高       | 中等               |

## 何时使用动画

动画是 UI 设计中一个重要且常用的元素，它通过动画的形式来展示内容的变化，让用户对内容有更好的理解。动画可以提高用户体验，提高用户对内容的理解，提高用户对产品的 Usage。但是用户的设备终究是开发者不可控的，在性能较低的设备上，动画会带来额外的性能压力甚至造成卡顿，因此动画的使用需要根据实际情况进行优化，用在必要的地方使用。
