Javascript 通过字符串生成颜色 ​

为什么要通过字符串生成颜色？ ​

在前端开发中，我们经常需要根据字符串生成颜色，比如在聊天室中，我们需要根据用户名生成颜色，以便于区分用户。或者在 echarts 中，我们需要根据数据生成颜色，以便于区分数据。我们没办法每次都有设计师给出颜色，所以需要自己做一个生成器。

如何通过字符串生成颜色？ ​

基础方案：十六进制哈希法 ​

通过字符串哈希生成固定长度的十六进制颜色代码，适合需要确定性映射的场景（相同字符串始终返回相同颜色）。

js
function stringToColor(str) {
  const hexChars = '0123456789ABCDEF'
  let hash = 0
  // 计算字符串哈希值
  for (let i = 0; i < str.length; i++) {
    hash = str.charCodeAt(i) + ((hash << 5) - hash)
  }
  // 生成颜色代码
  let color = '#'
  for (let i = 0; i < 6; i++) {
    const value = (hash >> (i * 3)) & 0xf
    color += hexChars[value % 16]
  }
  return color
}
// 示例
console.log(stringToColor('hello')) // 输出类似 #A3C8F2

原理：通过字符 ASCII 码计算哈希值，截取其中 6 位生成颜色代码。

优化方案：HSL 颜色空间法（推荐） ​

利用 HSL 的色相（Hue）参数生成高区分度且视觉友好的颜色，适合需要美观且可读性强的场景。

js
function stringToHSL(str) {
  let hash = 0
  for (let i = 0; i < str.length; i++) {
    hash = str.charCodeAt(i) + ((hash << 5) - hash)
  }
  // 色相范围 0-360，饱和度和亮度固定
  const h = Math.abs(hash % 360)
  return `hsl(${h}, 70%, 60%)`
}
// 示例
console.log(stringToHSL('world')) // 输出类似 hsl(145, 70%, 60%)

优势：通过固定饱和度和亮度，确保颜色明亮且易于区分。

扩展方案：第三方库集成 ​

使用 ​randomcolor 库实现专业级颜色生成，支持种子（Seed）参数确保相同字符串返回相同颜色。

  1. 安装依赖：
bash
npm install randomcolor
  1. 代码实现
js
import randomColor from 'randomcolor'

function getColorByString(str) {
  return randomColor({
    seed: str, // 以字符串为种子
    luminosity: 'bright', // 高亮度
    format: 'hex' // 输出十六进制格式
  })
}
// 示例
console.log(getColorByString('test')) // 输出类似 #FF6B6B

特性：支持亮度/饱和度预设、多颜色格式输出，且生成颜色符合视觉协调性。

应用场景对比 ​

方案名称适用场景优点缺点
十六进制哈希法标签分类、用户头像底色实现简单，无依赖颜色可能不够协调
HSL 颜色空间法数据可视化、图表配色颜色美观，区分度高需要手动控制参数
第三方库集成专业 UI 设计、主题系统颜色质量高，功能丰富需引入外部依赖，且已停止维护

高级优化技巧 ​

  1. ​ 避免颜色冲突 ​

    对哈希值加入素数扰动，减少不同字符串生成相同颜色的概率：

js
hash = hash * 31 + str.charCodeAt(i)
// 如果使用 hsl 则需要 防止数值溢出，并约束在色相范围内（0-359）
hash = hash % 360

  1. ​ 暗色模式适配 ​

    根据背景色动态调整亮度：

js
const lightness = isDarkMode ? '40%' : '70%'
return `hsl(${h}, 70%, ${lightness})`

  1. ​ 颜色缓存 ​

    使用 Map 缓存已生成的颜色，提升性能：

js
const colorCache = new Map()
function getColor(str) {
  if (colorCache.has(str)) return colorCache.get(str)
  const color = calculateColor(str)
  colorCache.set(str, color)
  return color
}

  1. 兼容性优化

    使用 hsl 是需要考虑兼容性的，在低版本浏览器中，hsl 颜色值可能会被解析为 rgb 颜色值，导致颜色显示不正常，这时可以转为 rgb 颜色值：

    公式与步骤 ​（兼容所有编程环境）：

    1. ​ 归一化输入值：将 H（0-360°）转为 0-1 范围（H'=H/360），S（0-100%）转为 0-1，L（0-100%）转为 0-1。

    2. 计算中间变量：

      • C=(1-|2L-1|)*s
      • X=C×(1−∣(H′×6)%2−1∣)
      • m=L−C/2

    3. ​ 根据 H'所在区间确定 RGB 初值：

      • 0 ≤ H' < 1/6 → (C, X, 0)
      • 1/6 ≤ H' < 2/6 → (X, C, 0)
      • 以此类推至 H'在 5/6 到 1 之间。

    4. 最终 RGB 值：将初值各分量加 m 后乘以 255 取整。

js
function hslToRgb(h: number, s: number, l: number) {
  h /= 360
  s /= 100
  l /= 100
  const C = (1 - Math.abs(2 * l - 1)) * s
  const X = C * (1 - Math.abs(((h * 6) % 2) - 1))
  let r: number, g: number, b: number
  if (h * 6 < 1) [r, g, b] = [C, X, 0]
  else if (h * 6 < 2) [r, g, b] = [X, C, 0]
  else if (h * 6 < 3) [r, g, b] = [0, C, X]
  else if (h * 6 < 4) [r, g, b] = [0, X, C]
  else if (h * 6 < 5) [r, g, b] = [X, 0, C]
  else [r, g, b] = [C, 0, X]
  const m = l - C / 2
  return [Math.round((r + m) * 255), Math.round((g + m) * 255), Math.round((b + m) * 255)]
}

完整代码实现： ​

js
const colorCache = new Map<string, string>();

interface StringToColorConfig {
  /** 颜色亮度，如果是深色尽量保持在 40 以下 */
  lightness?: number;
  /** 是否使用复杂的哈希算法，如果字符串长度较长，建议使用复杂的哈 */
  complex?: boolean;
}

/**
 * 将字符串转换为颜色
 * 此函数通过字符串生成一个哈希值，然后将该哈希值转换为HSL颜色空间中的颜色，最后转换为RGB格式
 * 这允许将唯一的颜色分配给任何给定的字符串对于相同的输入，生成的颜色将是相同的
 *
 * @param str 输入字符串，用于生成颜色
 * @param config 可选配置对象，包括颜色的亮度和是否使用复杂的哈希算法
 * @returns 生成的RGB颜色字符串
 */
function stringToColor(str: string, config?: StringToColorConfig) {
  // 解构配置对象，设置默认亮度值和复杂模式
  const { lightness = 60, complex = false } = config || {};
  const cacheKey = `${str}-${lightness}-${complex}`;

  // 检查缓存中是否已有该字符串对应的颜色，如果有则直接返回
  if (colorCache.has(cacheKey)) {
    return colorCache.get(cacheKey);
  }

  // 初始化哈希值
  let hash = 0;
  // 遍历字符串中的每个字符，生成哈希值
  for (let i = 0; i < str.length; i++) {
    // 根据配置选择是否使用复杂的哈希算法
    if (complex) {
      // 复杂哈希算法：使用31作为乘数，累加字符的ASCII值，以产生更均匀的哈希值，根据实际情况可以用更大的素数
      hash = hash * 31 + str.charCodeAt(i);
    } else {
      // 简单哈希算法：使用位移和减法来生成哈希值
      hash = str.charCodeAt(i) + ((hash << 5) - hash);
    }
  }
  // 确保哈希值为正数，并在色相范围内
  const h = Math.abs(hash % 360);
  // 将HSL值转换为RGB值
  const [r, g, b] = hslToRgb(h, 70, lightness);
  // 构造RGB颜色字符串
  const color = `rgb(${r},${g},${b})`;
  // 将字符串和生成的颜色存入缓存
  colorCache.set(cacheKey, color);
  // 返回生成的颜色
  return color;
}
